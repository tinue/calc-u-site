Setup

Installing on Windows and Linux

Download the Windows installer or the Linux AppImage from GitHub. The app has the same calculators, printer, cards, presets and debugger as the Mac app.

Windows

  1. From the latest GitHub release, download Calc-U-59-Setup.exe (most PCs) or Calc-U-59-Setup-arm64.exe (Windows on ARM).
  2. Run it. The installer isn't signed, so Windows SmartScreen may warn about an unrecognised app: choose More info, then Run anyway.
  3. Start Calc-U-59 from the Start menu.

Linux

  1. From the same release, download the AppImage for your machine: x86_64 for most PCs, aarch64 for ARM.
  2. Make it executable (chmod +x Calc-U-59-*.AppImage, or the file's Properties dialog) and run it. Nothing else needs installing.

Where your files go

Cards and the TI-58C's constant memory (ti58c.mem) are kept in Calc-U-59 in your home folder; debugger traces go there too. Settings › Files changes the card folder, the trace folder and the folder Open Preset starts in.

There is no iCloud on these platforms, so cards don't sync with the Apple apps — copy the .U59 files across if you want them there.
