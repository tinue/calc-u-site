Installing on Mac

Download the release from GitHub, then drag the app to Applications.

  1. Download the latest release DMG from GitHub.
  2. Double-click the DMG file to open it and show the installer window.
  3. Drag Calc-U-59.app to the Applications folder.
  4. Eject the disk image and launch the app from Applications.

The app is signed and notarized by Apple, so macOS opens it like any other application. It needs macOS 15.6 or later. Cards and the TI-58C's memory sync through iCloud with the iPhone and iPad app.
