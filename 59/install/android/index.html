Setup

Installing on Android

There is no Android app in a store: the web app installs from your browser instead, gets its own icon on the home screen and starts full screen, without the browser around it.

  1. Open calc-u.org/59/calc/app/ in Chrome.
  2. Tap Install in the banner that offers to install Calc-U 59. If there is no banner, open Chrome's ⋮ menu and choose Add to Home screen (in newer versions, Install app), then confirm.
  3. Start Calc-U 59 from its icon on the home screen or in the app drawer.

Other browsers, such as Samsung Internet, Firefox and Edge, have a similar Add to Home screen or Install command in their menu.

The installed app is the browser emulator in the iPhone app's portrait layout: the calculator fills the screen, and the chevron in the corner turns to the PC-100C printer's page and back. It has the TI-59, TI-58 and TI-58C, all fourteen modules, presets and Settings. The debugger is not in it; it needs the wide layout of the browser emulator on a computer, or the full app.

Offline and updates

Once installed, the app runs all three calculators without a connection, with module 01 (Master Library). Any other module needs the network the first time you load it. When a new version is out, the app updates itself.

Where your files go

The TI-58C keeps its constant memory on the phone between launches. Cards last until you close the app: download a card from the card list to keep it, and upload a .U59 file to fit it again.

Preset opens a .ti59, .ti58 or .ti58c file from the phone's storage; files are read on the phone and never uploaded anywhere.
