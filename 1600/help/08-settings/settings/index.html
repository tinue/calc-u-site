Chapter 8 · Settings

Settings of Calc-U-1600

The settings file, where it lies, and the keys every product of the family has are described in Settings. This page lists what Calc-U-1600 adds: its file's name, the names it gives the family's keys, and its own keys.

Calc-U-1600's settings file is Calc-U-1600.ini. File ▸ Settings… opens the settings dialog; a change applies at once.

The dialog

  • General ▸ Startup model: the model to start with: the one used last, PC-1500, PC-1500A or PC-1600 ([startup] model).
  • Startup presets: one per model, see Startup presets below.
  • Storage ▸ Save folder and Cassettes: where your saved modules, disks and cassettes go (Media).
  • Folders: where the file dialogs start, see Folders.
  • Tracing: the trace folder and the size limit of a trace (the family's keys).
  • Serial ports ▸ Link folder: where the serial port files go, with their current paths while the ports are open (COM ports). Not on Windows.
  • Debugger: the debug server for VS Code, its port, its status, and Disconnect (Debugger).
  • App log ▸ App log level: how much the app log keeps (The app log).

The Web frontend shows the startup model, the startup presets, the app log level and, under Storage, a note that it keeps your modules, disks and cassettes in the browser's storage for the page.

Startup presets

[preset] <model> of the family has one key per model here:

  • [preset] PC-1500: the startup preset of the PC-1500; empty: none.
  • [preset] PC-1500A: the startup preset of the PC-1500A; empty: none.
  • [preset] PC-1600: the startup preset of the PC-1600; empty: none.

The first start sets each to the model's bundled startup preset: the CE-150 and a CE-163F on the PC-1500 and PC-1500A, the CE-1600P with its floppy and a CE-1600M and a CE-1601M (a RAM disk) on the PC-1600.

A startup preset is applied at each start and each switch to its model (Presets).

Folders

[folders] <kind> of the family has four kinds here. Each is where a file dialog starts: the folder last used (written by the app), or a fixed folder given as fixed:<folder>.

Key Dialog label Where it applies
[folders] presets Presets folder File ▸ Load Preset…
[folders] basic-programs BASIC folder File ▸ Load BASIC Program…
[folders] machine-code Assembly folder File ▸ Load Machine Code…
[folders] host-drive Host drive folder File ▸ Host Drive… (the folder last mounted by default)

Debug server

  • [debug] dap-enabled: the debug server for VS Code (DAP, on 127.0.0.1 only): true or false; false by default. In the dialog: Debugger ▸ Debug server (DAP).
  • [debug] dap-port: the port of the debug server, 1024 to 65535; any other value counts as missing, and the port is 32168. In the dialog: Debugger ▸ Port.

Starting Calc-U-1600 with --dap <port> turns the server on for that run only and leaves both keys as they are (Debugger).

Window

[window] <key> of the family has these keys here, all written by the app:

  • [window] x, [window] y: the window's left and top edge.
  • [window] width, [window] height: the window's size; 900 by 700 by default.

The windows come back at their last normal size and place, never maximised or full screen.
