Chapter 10 · Reference

Calc-U-1600 reference

This chapter describes the files Calc-U-1600 reads and writes, each in its current version, and the keyboard map. What every product of the family shares (the grammar of the preset format, the rules of the settings file, the glossary) is in the shared reference; the pages below add what is Calc-U-1600's own.

File Extension Version Where
Preset .pc1500, .pc1500a, .pc1600 format-version: 2 Preset sections
Module definition (a memory module, and a saved battery-backed module) .module.yaml format: memory-module, format-version: 1 Module definition format
Floppy disk .floppy.yaml format-version: 2 Media files
Cassette definition (with its sound file) .cassette.yaml and .wav format: cassette, format-version: 1 Media files
Settings file Calc-U-1600.ini format-version = 1 below
Keyboard map (built in) Keyboard map

What a module definition expresses, and why, is described in Module definitions; the format page here is how it is written.

The settings file

Calc-U-1600 keeps its settings in one file, Calc-U-1600.ini, in the folder that Settings names for each platform, with <Product> as Calc-U-1600.

The rules of the file (its sections, how a missing or unknown key is treated, which keys the product writes itself) are those of the shared reference and the shared Settings chapter; Calc-U-1600's own keys and the names it gives the family's keys are in Settings.
